# InAmigos Foundation — Frontend Website

🌐 **Live Demo:** https://imaginative-banoffee-19ce8e.netlify.app/

## About
A frontend website for InAmigos Foundation, a non-profit organization focused on education, environmental conservation, animal welfare, women empowerment, and community development.

## Features
- Foundation introduction and mission
- Projects and social initiatives
- Information about the organization's impact
- Volunteer and contact sections
- User-friendly website interface

## Tech Stack
- Frontend: HTML, CSS, 
- Deployment: Netlify

## Note
This project is **frontend-only**. It is a static website interface and does not include backend services, database integration, or functional server-side processing.
